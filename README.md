# 门店内容对比弹窗

打开 `index.html` 即可预览，无需安装依赖。也可在此目录启动静态服务器。

- 弹窗：375 × 571 px；图片区域：319 × 240.68 px。
- 四组原图按 tab 顺序轮播：外显小图、头图、相册、推荐菜。
- 图片底部增加 228 × 30 px 联动 tab（x=73.5，y=266.5）。12/20 Regular，选中态带浅灰胶囊和 0.5 px 内描边。tab 上方 18 px 至底部有横跨整行的渐变模糊，强度渐增至 4 px。点击切换图片并从右向左重新播放；自动轮播同步选中态。支持方向键和 Home/End 切换。
- 每组先停留 750 ms，再用 2400 ms 从右向左揭示有内容状态，停留 1350 ms 后用 540 ms 向左平移切换。前后两组同时移动，不淡出或清空画面。点击 tab 向对应方向平移切换，随后重新扫线；自动轮播（含末项回到首项）始终向左。
- 支持拖动分隔线、方向键调整、Escape 关闭。系统开启减少动态效果时，默认静止在 50% 对比位置。
- 标题：PingFang SC Semibold 28/44；说明：Regular 14/21。
- 主按钮发出冒泡的 `ai-assist` 自定义事件并关闭弹窗，接入实际业务时监听此事件。
- 静态核对：`?still&slide=1&split=50`；slide 范围 0–3，split 为无内容状态显示的百分比。
